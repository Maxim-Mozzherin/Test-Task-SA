DBEditor – простой редактор таблиц для PostgreSQL.

Требования:
- Windows 10/11
- PostgreSQL установлен
- Создана база данных с именем: Test_DB
- Имя пользователя: postgres (или другой, по необходимости)
- Пароль будет введен вручную при запуске приложения

Инструкция по запуску:
1. Убедитесь, что PostgreSQL запущен.
2. Создайте базу данных:
   - Откройте psql или pgAdmin
   - Выполните команду:
       CREATE DATABASE "Test_DB";
3. Скопируйте DBEditor.exe в любое удобное место.
4. Запустите DBEditor.exe.
5. В появившемся окне введите пароль пользователя PostgreSQL.
6. После подключения вы сможете:
   - Просматривать таблицы базы
   - Создавать новые таблицы
   - Добавлять/удалять поля
   - Редактировать и сохранять данные

Примечание:
- Приложение не включает саму базу.
- Все изменения будут происходить в базе Test_DB, которую создает пользователь.
- Первичный ключ каждой новой таблицы создается автоматически как "id".
